# GPT Image GIF Playbook

从 X 公开原帖独立采集的中文案例、公开提示词和工作流索引；不是参考合集的镜像。**已公开发布：** https://github.com/LPJXLOVE/gpt-image-gif-playbook

## V2 收录

- **37 个 GIF 案例帖/组 + 6 个视频工作流**，共 43 条；本轮实增 19 个GIF组、5 个视频工作流。
- 提示词按条目分：**完整 15、节选 3、未采集 25**。完整公开提示词另存 **15 份文件**；一个文件可包含同一流程多个步骤，不按步骤虚增案例。
- 公共搜索 **16 次**，去重候选 **233 条**，批量原帖核验 **3 次**。搜索未穷尽分页，不声称收齐全网。

> 不下载、不上传第三方 GIF、视频或输入图。公开可看不等于可复制或可商用。第三方作品、提示词、人物、角色和品牌不受本仓库 MIT 授权。模型功能、帧数、速度、成本与成功率均是发布者陈述，未作为官方保证或独立复现实验。

## GIF 案例

每行按独立帖子/作品组计数。SocialSight 10条为同一线程10个不同帖子/场景，Daft_Trade 4条为4个不同测试帖；大肥鱼4附件、AI梗4附件、橘猫9宫格、纯文字猫3结果、十二心情总览均各计一组。发布者署名不等于已核验原创归属。

“完整”只表示作者公开的该条指令原文已核实，不保证参考图已授权或提示词能稳定执行；“节选”表示仅取得约束片段/动画短指令，缺少前置指令；“未采集”不等于断言作者在其他地方从未公开。没有提示词绝不根据画面反推冒充。

媒体类型来自X返回数据，不主动重新托管作品，未逐帧目视评测。纯营销、纯转帖、无法绑定作品、仅截图或模型不对应的内容不凑数收录。各类实验的不足也予以记录。
